## Installation

```bash
pip install tiktok-live-api
```

## Quick Start

```python
from tiktok_live_api import TikTokLive

client = TikTokLive("streamer_username")

@client.on("connected")
def on_connected(event):
    print(f"Connected to @{event['uniqueId']}")

@client.on("chat")
def on_chat(event):
    print(f"[chat] {event['user']['uniqueId']}: {event['comment']}")

@client.on("gift")
def on_gift(event):
    diamonds = event.get("diamondCount", 0)
    print(f"[gift] {event['user']['uniqueId']} sent {event['giftName']} ({diamonds} diamonds)")

@client.on("like")
def on_like(event):
    print(f"[like] {event['user']['uniqueId']} liked (total: {event['totalLikes']})")

@client.on("follow")
def on_follow(event):
    print(f"[follow] {event['user']['uniqueId']} followed")

@client.on("roomUserSeq")
def on_viewers(event):
    print(f"[viewers] {event['viewerCount']} watching")

client.run()
```

## Live Captions (legacy)

The Live Captions service is no longer offered to new customers. Existing caption customers can keep using the `TikTokCaptions` client in this package; see the [Captions SDK reference](/captions/sdk). For free captions on any stream, listen for the native [`caption` event](/websocket/events#caption) with `@client.on("caption")`.

## Events

All events from the [WebSocket Events](/websocket/events) reference are available via the `@client.on()` decorator.
