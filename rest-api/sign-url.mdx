## `POST` `/webcast/sign_url`

Sign a TikTok LIVE request URL you built yourself. The URL must point at an approved TikTok host; the API returns it ready to call.

**Authentication:** pass your API key (`apiKey` query parameter or `x-api-key` header). The endpoint is also callable without a key at a low per-IP rate; a key lifts that cap.

**Response data:** `signed_url` (your URL, ready to call), `user_agent` (send exactly this User-Agent with the request) and `cookies` (an opaque value to send as-is with the request, may be empty). Treat every returned value as opaque and short-lived; request a new one rather than reusing old values.

**Prefer parsed data?** Most integrations do not need to sign anything. [`/webcast/room_info`](/rest-api/room-info), [`/webcast/check_alive`](/rest-api/check-alive) and the [WebSocket API](/websocket/connection) return parsed results directly.

**Errors:** a URL outside the approved hosts is rejected with a non-zero `status_code` and a `message`. Calls count toward your plan's request limits (see [Rate Limits](/reference/rate-limits)).

### Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `url` | string | Yes | The TikTok URL to sign |

### Response

```json
{ "status_code": 0, "data": { "signed_url": "...", "user_agent": "...", "cookies": "..." } }
```

### Examples

<CodeGroup>
```javascript Node.js
const res = await fetch('https://api.tik.tools/webcast/sign_url?apiKey=YOUR_KEY', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ url: 'YOUR_TIKTOK_LIVE_URL' })
});
const data = await res.json();
console.log(data.data.signed_url);
```

```python Python
import requests
res = requests.post('https://api.tik.tools/webcast/sign_url',
    params={'apiKey': 'YOUR_KEY'},
    json={'url': 'YOUR_TIKTOK_LIVE_URL'})
print(res.json()['data']['signed_url'])
```

```bash cURL
curl -X POST "https://api.tik.tools/webcast/sign_url?apiKey=YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url": "YOUR_TIKTOK_LIVE_URL"}'
```

```java Java
HttpClient client = HttpClient.newHttpClient();
String json = "{\"url\": \"YOUR_TIKTOK_LIVE_URL\"}";
HttpRequest req = HttpRequest.newBuilder()
    .uri(URI.create("https://api.tik.tools/webcast/sign_url?apiKey=YOUR_KEY"))
    .header("Content-Type", "application/json")
    .POST(HttpRequest.BodyPublishers.ofString(json))
    .build();
HttpResponse<String> res = client.send(req, HttpResponse.BodyHandlers.ofString());
System.out.println(res.body());
```

````go Go
payload := bytes.NewBufferString(`{"url":"YOUR_TIKTOK_LIVE_URL"}`)
resp, err := http.Post(
    "https://api.tik.tools/webcast/sign_url?apiKey=YOUR_KEY",
    "application/json", payload)
if err != nil { log.Fatal(err) }
defer resp.Body.Close()
body, _ := io.ReadAll(resp.Body)
fmt.Println(string(body))
````

```csharp C#
using var client = new HttpClient();
var json = new StringContent(
    @"{""url"":""YOUR_TIKTOK_LIVE_URL""}",
    Encoding.UTF8, "application/json");
var res = await client.PostAsync(
    "https://api.tik.tools/webcast/sign_url?apiKey=YOUR_KEY", json);
Console.WriteLine(await res.Content.ReadAsStringAsync());
```
