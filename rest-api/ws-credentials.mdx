## `POST` `/webcast/ws_credentials`

Get everything needed to open a live WebSocket connection to a creator's room from your own client, instead of using the managed connection at `wss://api.tik.tools`.

**When to use:** advanced integrations that must connect from their own network. Most users should use the managed [WebSocket API](/websocket/connection) or the [Node.js SDK](/sdks/nodejs); the SDK's Direct mode calls this endpoint and handles the response for you.

**Authentication:** pass your API key (`apiKey` query parameter or `x-api-key` header).

**Response data:** `ws_url` (the connection URL), `ws_host`, `room_id`, `cluster_region`, `user_agent`, `cookies` (an opaque value to send as-is) and connection setup data used by the SDK. Credentials are short-lived; request fresh ones for each connection.

**Region (`region`):** selects which host string is returned. `us` (default) works for virtually every room, `eu` returns the EU host, and `global` returns the nearest-edge host (recommended outside the US).

**Limits:** direct connections are limited per IP (a handful of concurrent connections). If you need more, use the managed WebSocket, where your plan's connection limit applies instead. Calls count toward your plan's request limits (see [Rate Limits](/reference/rate-limits)).

### Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `unique_id` | string | Yes | TikTok username |
| `region` | string | No | Host region: `us` (default), `eu`, or `global` (nearest edge, recommended outside the US) |

### Response

```json
{ "status_code": 0, "data": { "ws_url": "wss://...", "ws_host": "...", "room_id": "...", "cluster_region": "...", "user_agent": "...", "cookies": "..." } }
```

### Examples

<CodeGroup>
```javascript Node.js
const res = await fetch('https://api.tik.tools/webcast/ws_credentials?apiKey=YOUR_KEY', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ unique_id: 'username' })
});
const { data } = await res.json();
console.log('WS URL:', data.ws_url);
```

```python Python
import requests
res = requests.post('https://api.tik.tools/webcast/ws_credentials',
    params={'apiKey': 'YOUR_KEY'},
    json={'unique_id': 'username'})
data = res.json()['data']
print(f"WS URL: {data['ws_url']}")
```

```bash cURL
curl -X POST "https://api.tik.tools/webcast/ws_credentials?apiKey=YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"unique_id": "username"}'
```

```java Java
HttpClient client = HttpClient.newHttpClient();
String json = "{\"unique_id\": \"username\"}";
HttpRequest req = HttpRequest.newBuilder()
    .uri(URI.create("https://api.tik.tools/webcast/ws_credentials?apiKey=YOUR_KEY"))
    .header("Content-Type", "application/json")
    .POST(HttpRequest.BodyPublishers.ofString(json))
    .build();
HttpResponse<String> res = client.send(req, HttpResponse.BodyHandlers.ofString());
System.out.println(res.body());
```

````go Go
payload := bytes.NewBufferString(`{"unique_id":"username"}`)
resp, err := http.Post(
    "https://api.tik.tools/webcast/ws_credentials?apiKey=YOUR_KEY",
    "application/json", payload)
if err != nil { log.Fatal(err) }
defer resp.Body.Close()
body, _ := io.ReadAll(resp.Body)
fmt.Println(string(body))
````

```csharp C#
using var client = new HttpClient();
var json = new StringContent(
    @"{""unique_id"":""username""}",
    Encoding.UTF8, "application/json");
var res = await client.PostAsync(
    "https://api.tik.tools/webcast/ws_credentials?apiKey=YOUR_KEY", json);
Console.WriteLine(await res.Content.ReadAsStringAsync());
```
