<Warning>
Live Captions has been retired and its WebSocket no longer accepts connections. This page stays as a historical reference only. For captions on any stream, use TikTok native captions: the [`caption` event](/websocket/events#caption) on the standard LIVE WebSocket.
</Warning>

## What is this?

Live Captions was a paid transcription and translation service for TikTok LIVE streams, delivered over a dedicated WebSocket. It has been retired.

## Quick Example

```javascript
import WebSocket from 'ws';

const ws = new WebSocket(
  'wss://api.tik.tools/captions?uniqueId=streamer&apiKey=YOUR_KEY&translate=en&max_duration_minutes=120'
);

ws.on('message', (data) => {
  const msg = JSON.parse(data.toString());
  if (msg.type === 'caption') console.log(msg.text);
  if (msg.type === 'translation') console.log(msg.text);
});
```
