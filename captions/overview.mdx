<Warning>
Live Captions is a legacy service and is no longer offered to new customers. Existing caption customers keep full access, and this page stays as a reference for them. For free captions on any stream, use TikTok native captions: the [`caption` event](/websocket/events#caption) on the standard LIVE WebSocket.
</Warning>

## What is this?

Live Captions was a paid transcription and translation service for TikTok LIVE streams, delivered over a dedicated WebSocket. It is kept running for existing caption customers only. New customers cannot sign up for it.

## Quick Example

```javascript
import WebSocket from 'ws';

const ws = new WebSocket(
  'wss://api.tik.tools/captions?uniqueId=streamer&apiKey=YOUR_KEY&translate=en&max_duration_minutes=120'
);

ws.on('message', (data) => {
  const msg = JSON.parse(data.toString());
  if (msg.type === 'caption') console.log(msg.text);
  if (msg.type === 'translation') console.log(msg.text);
});
```
